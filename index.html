🤖 AI 設定

全站的 AI 生成功能（測驗反思、整合報表、善意練習反思等）需要你自己提供任一供應商的 API Key 才能使用。金鑰只存在這次瀏覽器分頁的暫存記憶體（sessionStorage），關閉分頁就會清除，不會被送到任何我們自己的伺服器。

可在 console.anthropic.com 取得金鑰。支援瀏覽器直接呼叫，穩定性較高，建議優先使用。

可在 aistudio.google.com/apikey 取得金鑰。提醒：Gemini API 在純前端（瀏覽器直連）環境下偶有跨網域（CORS）限制，若連線失敗，畫面會顯示原因並建議改用 Claude。

可在 platform.openai.com/api-keys 取得金鑰。提醒：OpenAI 官方 API 目前不支援瀏覽器直接呼叫（CORS 限制），純前端環境下很可能連線失敗——這是 OpenAI 服務端的既有限制，不是金鑰或設定錯誤，若失敗建議改用 Claude。

Agnes AI 提供 OpenAI 相容介面，可作為替代選項。
